# EchoMind 产品设计笔记

## 命名

EchoMind（回声）：会议、文档都是"说过的话"，EchoMind 让这些话留下回声——任何时刻提问，都能得到带出处的回答。

## 关键决策

- 默认切块大小 500 字符，相邻块重叠 50 字符。
- 向量模型使用 bge-small-zh-v1.5，输出 512 维，本地 CPU 运行，零成本。
- 检索默认向量召回 20 条、BM25 召回 20 条，RRF 融合后取前 5 条送入大模型。
- 大模型默认 DeepSeek，走 OpenAI 兼容协议；未配置 API Key 时自动进入 mock 模式，直接回显检索结果。

## 面试预演

面试官最可能追问的三个问题：为什么需要混合检索、HNSW 索引的原理、chunk 大小如何影响召回效果。每一个都要能给出实验数据支撑。
